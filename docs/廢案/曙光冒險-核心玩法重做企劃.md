# 曙光冒險 PC 版重製企劃

2026-10-14 定案（玩家的選擇）：回到曙光冒險，改成 **只在電腦玩的橫向 RPG**，同時重做 **戰鬥** 和 **野外探索**。
玩家的想法：路走錯了。RPG 需要花時間玩，一般玩家沒有時間一直拿手機玩，應該一開始就做 PC 版。

2026-10-15 第一版試玩後，玩家：「玩起來很怪」——野外、戰鬥、操作、選單全部都怪（人物太小、側欄佔位置、走路卡、換地圖跳色；角色小畫面空、時間軸看不懂、背影怪、介面擠；按鍵不習慣、滑鼠誤觸、按鍵不一致、反應慢；舊畫面擠一欄、風格不一致、像手機硬放大、字太小）。

**目前進度：** 第二版試玩（同一個連結）：https://claude.ai/artifact/WMRjjmoeuc389MQgjS1RBS 。做了哪些、怎麼做的，見〈曙光冒險-設計紀錄〉的「PC 版重製」。

## 一、定案

| 項目 | 選擇 |
|---|---|
| 平台 | **只做 PC**，不再顧慮手機螢幕和觸控 |
| 畫面 | 遊戲畫面 480×270（16:9）；野外放大 1.5 倍；字最小 9、一般 11 |
| 操作 | **鍵盤為主＋滑鼠輔助**，照一般 PC RPG 習慣 |
| 戰鬥 | 單人回合制，**每回合各動一次**（速度快的先動），**側面對戰** |
| 遇敵 | 地圖上看得到魔物，碰到才進戰鬥；先制・偷襲 |
| 野外 | **自由移動**＋無縫大地圖＋可互動 |
| 保留 | 劇情・世界觀・角色、魔物和美術、裝備・掉寶・鐵匠、職業・技能・天賦 |
| 試玩 | 第一章開頭（萌芽鎮・晨霧道路・風車丘陵到磨石魔像），另一個連結，正式版不動 |

## 二、操作

| 鍵盤 | 功能 |
|---|---|
| WASD／方向鍵 | 移動（8 方向） |
| Shift | 跑步（只有跑步，不再兼當返回） |
| Z／空白鍵／Enter | 決定・調查・下一句 |
| X／Esc／Backspace | 返回；野外沒開任何東西時＝開選單 |
| Tab／M | 開選單 |
| E | 野外技能（燒藤蔓、推石頭） |
| 數字鍵 | 戰鬥：指令 1〜5、技能 1〜9、目標 1〜N |
| C | 戰鬥動畫 ×2 |

滑鼠：移到項目上就選中，左鍵點項目＝決定，右鍵＝返回；點空白處不會誤觸；對話框點哪裡都是下一句；滾輪＝上下選；戰鬥中直接點魔物＝攻擊牠。
第一次開 PC 版：文字顯示快、對話字大、戰鬥動畫 ×2（設定裡可以改）。

## 三、野外

- 整個畫面都是地圖，放大 1.5 倍（看得到約 20×11 格）；資訊浮在角落：左上地名・天氣、右上追蹤的任務、左下 HP・MP。
- **自由移動**：8 方向、滑順，沿著牆會滑過去，靠近窄路口自動對齊；Shift 跑步。撞到門・出口・懸崖・魔物・裂紋石頭・地圖邊緣時，照原本的規則處理（進門、換地圖、跳下去、開戰、推石頭）。
- **無縫**：相連的野外地圖直接走過去；隔壁那段用隔壁自己的配色畫，走過去不跳色。
- **野外技能**：燒藤蔓（風車丘陵撿到火打石）、推石頭（藤蔓後面的大力手套）；**旅人石碑**（萌芽鎮・晨霧道路・風車丘陵）互相傳送。
- **先制・偷襲**：從背後碰到魔物＝第一回合魔物來不及動；被追上時背對著牠＝第一回合只有魔物能動。

## 四、戰鬥：每回合各動一次＋側面對戰

- 每回合大家各動一次，速度快的先動；防禦・道具・逃跑那回合最先動；搶先類技能提前。
- 左上兩排頭像：**這回合**（正在動的金框，動完的拿掉）和**下回合**的順序；選指令時，這回合的順序跟著你選的指令變。
- 主角在左邊面向右、魔物在右邊（都放大）；魔物腳下是名字和 HP，頭上是下一招要做什麼。
- 輪到你：主角旁邊跳出直列指令（攻擊・技能・道具・防禦・逃跑），技能清單在旁邊；下面左邊是訊息和說明，右邊是主角狀態。
- 主角側面戰鬥圖：交給 Codex（〈曙光冒險-Codex主角側面戰鬥圖任務〉），畫好之前先用野外的側面圖放大頂著。
