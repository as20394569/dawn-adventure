## 三、不要再出現的

- 即時動作戰鬥
- 副本式探索
- 第一人稱迷宮（含千層迷宮）
- 卡牌戰鬥／牌組
- 破綻與追擊
- 戰後評價
- 自動戰鬥（戰鬥 ×2 速可以）
- 元素反應系統（現在只有種族弱點）
- 只限 PC 重做的：行動順序時間軸（快・普・重、主角連動兩次）、野外右側欄＋下方狀態列。

## 四、要拿回某個廢案時

```
git fetch origin
git checkout archive/card-v14.33          # 換成分支名
```

- 各分支都是當時完整的程式，照當時的方法建置。
- PC 重做的可玩版在 `archive/pc-remake` 的 `pc/web/`，說明見 `pc/README.md`。
