## 1. 跟現在 v11 的差別

| 項目 | 現在（v11） | 草案（v12） |
|---|---|---|
| 回合流程 | 回合開始所有人先選好指令，再依先制度和速度執行 | 先依速度排好本回合順序，**輪到誰誰才選指令**；畫面上方顯示行動順序 |
| 先制技能 | 本回合插隊 | 「搶先」：使用後**下一回合排第一** |
| 防禦 | 本回合減傷 | 減傷持續到**自己下一次行動開始** |
| 職業招式 | 全職業共用「招式點」（普攻打中、被打 +1） | **每個職業有自己的核心資源和規則**，招式點取消 |
| 技能 | 只有 MP 消耗 | 加上**冷卻**、學會次數依技能等級、搶先 |
| 天賦 | 3 流派×5 層×二選一＋招式強化樹，大多是數值 | 3 流派×3 層×二選一＋**核心天賦三選一**，以改規則為主；點數上限 20 |
| 寶珠 | 主動＝技能來源；被動大多是數值 | **取消**。技能改由職業（等級學會）和武器（用滿次數學會）提供；被動的互動效果改成飾品特性 |
| 附魔 | 附魔寶石改變武器屬性並附加效果 | **取消**。武器屬性只來自武器本身 |
| 武器 | 數值、被動、特技；每把還有 2 招已經沒作用的舊主動技 | 每把帶 1 招武器技能；武器種類有固定規則；一般武器＝成長型，專屬武器＝Build 型 |
| 飾品 | 數值 | 改成 Build 型：每個加 1 條特性 |
| 連段 | 全職業通用 | 改成天賦提供的規則（例：劍士「流水」） |
| 效果 | 寫在技能裡面 | **效果獨立定義、有 ID**，技能／天賦／狀態／裝備用 ID 引用 |
| 觸發順序 | 系統 → 反應 → priority | priority → 九層來源順序 → 行動順序 → 建立順序 → 穩定 ID |
| 測試 | 23 項測試＋平衡報告 | 規格 A～H 回歸關卡、平衡修改單、回歸報告、隨機性質測試、更多指標和自動警告 |

## 2. 規則層

### 2.1 戰鬥狀態機（規格 §9）
`INITIALIZING → BATTLE_START → ROUND_START → TURN_ORDER → WAITING_ACTION → ACTION_PREPARE → ACTION_EXECUTION ↔ EVENT_RESOLUTION ↔ REACTION_RESOLUTION → ACTION_END →（下一位行動者 | ROUND_END）→ VICTORY_CHECK →（ROUND_START | BATTLE_END）`

- **TURN_ORDER**：依行動速度排序（速度 × 能力等級；麻痺 ×0.25）。同速時用本回合固定亂數，再用穩定 ID。有「搶先」的排最前、有「延後」的排最後。
- **輪到英雄才選指令**；輪到魔物時由 AI 當場決定，所以魔物看得到英雄剛做了什麼。
- 畫面上方顯示本回合的行動順序（小頭像，目前行動者發亮）。
- 防禦、道具、逃跑都在自己的回合使用。
- 蓄力技能：蓄力後，下一次輪到自己時自動施放。
- 狂怒（頭目最後階段）：每 2 回合在順序最後多排一次行動。

### 2.2 回合開始、單一行動、回合結束（規格 §7）
- **回合開始**：重置回合次數限制與回合資源 → 回合開始的狀態 → 職業 → 天賦 → 裝備 → 事件清算 → 失去戰鬥能力判定 → TURN_ORDER。
- **單一行動**：行動開始 → 行動前觸發 → 合法性 → 支付成本 → 施放 → 決定目標 → 命中／閃避 → 會心 → 效果 PRE → 傷害管線（基礎 → 攻擊方 → 防禦方 → 技能 → 天賦 → 裝備 → 狀態 → 其他）→ MAIN → POST → 狀態變化 → 觸發 → 清算 → 失去戰鬥能力判定 → 行動結束 → 追加／反應。多段技能每一段各自跑「命中 → 效果 → 觸發 → 判定」。
- **回合結束**：狀態（中毒、灼傷…）→ 職業 → 天賦 → 裝備 → 清算 → 判定 → 持續時間遞減 → 到期移除 → 清理 → 勝敗判定。

### 2.3 觸發的先後（規格 §6）
同一個事件引發好幾個觸發時：**priority 大的先**；priority 相同時依來源層級：
1 系統強制 → 2 防止死亡／取消／替代 → 3 中斷／攔截／保護／反應 → 4 目前的技能 → 5 職業 → 6 天賦 → 7 裝備 → 8 狀態 → 9 敵人／場地／其他；
再依來源角色的行動順序 → 建立順序 → 事件序號 → 穩定 ID。不依賴資料載入順序。

### 2.4 狀態
- **施加流程**：目標合法 → 絕對免疫 → 條件免疫（例：火系不會灼傷）→ 抗性（異常抗性%）→ 成功率 → 既有狀態 → 疊層 → 持續時間 → 寫入 → 「狀態施加」事件 → 觸發。
- **移除流程**：請求 → 不可移除檢查 → 移除原因 → 保護／替代 → 正式移除 → 「狀態移除」事件 → 觸發。
- **每個「每回合」都寫明時間點**：

| 狀態 | 持續 | 遞減／判定時間點 |
|---|---|---|
| 中毒、灼傷 | 直到治好 | 傷害在回合結束 |
| 麻痺 | 直到治好 | 自己行動開始時 25% 無法行動 |
| 睡眠 | 1～3 次行動 | 自己行動開始時 |
| 潮濕、纏繞 | 3 | 擁有者行動結束時 |
| 護盾 | 2 | 擁有者行動開始時（護到第 2 次自己行動前） |
| 防禦中 | 到下一次自己行動 | 擁有者行動開始時移除 |
| 煙幕 | 3 | 擁有者行動結束時 |
| 能力等級 ±1～3 | 3 | 擁有者行動結束時 |
| 退縮 | 本回合 | 回合結束清除（只有比對手先行動才有用） |
| 破防 | 跳過 1 次行動，受到傷害 +25%（頭目）／+35% | 下一次自己行動結束時解除 |
| 凍結 | 下一次行動 | 自己行動開始時 |

### 2.5 技能規則
- **冷卻**：以「自己的行動次數」計算，自己行動結束時 −1。
- **搶先**：使用後，下一回合在 TURN_ORDER 排第一。
- **使用次數限制**：每場次數（例：時停每場 1 次）。
- **學會規則**：職業技能依等級學會；武器技能裝備時可用，使用 N 次後永久加入技能庫（N 依技能等級，見 §5）。
- **進化**：保留兩階段、每階段「強攻／附加」二選一（見 §6.2）；原本的「MP−40%」改成「冷卻−1」（沒有冷卻的技能仍是 MP−40%），原本的「先制」改成「搶先」。

### 2.6 效果定義（規格 §4）
所有效果獨立登錄：`id、effect_type、target_rule、value_formula、conditions、tags、event_flags、follow_up_effects`。技能、天賦、狀態、裝備只記效果的 ID。ID 永久不變，顯示名稱不當成邏輯 ID。

### 2.7 防止無限循環（規格 §8）
事件鏈深度上限 8；觸發上限：每次行動 32、每回合 96、每場 600；同一個來源在同一條事件鏈裡最多重入 2 次。超過就停止產生新事件，並輸出完整事件鏈。

### 2.8 失去戰鬥能力（規格 §6）
完成最小不可分割的效果 → 失去戰鬥能力 PRE（不屈、復活之類的防止／替代）→ 再次確認 → MAIN → 清理 → POST → 勝敗判定。

## 4. 天賦（規格 §2：以改規則為主，純數值只當輔助）

### 4.1 架構
- 每個職業 **3 個流派**，每個流派 **3 層**（各花 1／2／3 點），每層二選一。
- 外加一排**核心天賦**，三選一，花 4 點，要在該流派投入 6 點才能選。核心天賦彼此衝突，**只能有 1 個**。
- 每個選項標示類型：〔規則〕〔互動〕〔轉換〕〔數值〕。每一層最多只有 1 個〔數值〕選項。
- 點數：Lv2 開始每 2 級 1 點，**上限 20 點**（全部點滿要 22 點，所以一定要取捨）。
- 第 3 層和核心天賦要先完成「天賦覺醒」（Lv14，現有劇情）。
- 原本的「分支共鳴」（每 5 點給數值）和「職業招式強化樹」取消，招式的強化放進各流派。
- 舊存檔：全部天賦退點一次，會跳出說明。

## 5. 技能（規格 §2、§4）

### 5.1 共通規則
- **冷卻等級**：一般 0；進階 1（不能連續兩次）；強力 2；終極 3。
- **學會次數**：一般 6 次、進階 10 次、強力／終極 14 次。已經學會的維持學會。
- 範圍技能：多個目標時每隻 ×0.75；連鎖：主目標 100%、其他 50%（不變）。
- 每個技能都有完整欄位：目標規則、消耗、冷卻、搶先、命中、會心、效果、需求、次數限制、學會規則。

## 9. 測試與平衡流程（規格 §12～§17）
- **回歸關卡**：A 資料（Schema、ID、引用、版本、遷移）、B 核心（傷害、治療、資源、狀態、死亡、勝敗）、C 事件（PRE／MAIN／POST、priority、parent／root、佇列、循環上限）、D 內容、E 固定案例（固定種子比對事件序列）、F Build 矩陣、G 壓力（大量事件、多段、多目標、長戰鬥、極端層數）、H 存檔遷移。
- **隨機性質測試**：每次 1,000 場隨機內容戰鬥，檢查 HP 不超出範圍、佇列一定清空、沒有非法狀態轉移。
- **新增指標**：最高單回合傷害、資源產生／消耗／溢出、狀態與控制覆蓋率、死亡率、跨敵人表現。
- **自動警告**（只產生警告和證據，不改資料）：純上位、零使用率、單一 Build 支配、事件循環、無限追加／反擊／資源／治療／狀態、永久控制、無敵、數值溢位、敵人唯一解／無解。
- **平衡修改單**：每次調數值都有一份記錄（舊值、新值、原因、預期影響、測試計畫、驗收標準、結果），附上修改前的基準，通過才接受，否則回滾。
- **回歸報告**：每次版本輸出一份（測試數、失敗、指標差異、新增／解決的警告、結論）。
