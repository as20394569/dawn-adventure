# 平衡修改單（Balance ChangeSet）

規格 v1.1 §15：每次調整數值都要有一份修改單。修改前先跑 `node tools/play.js tools/btest.js --sims` 存下基準（tools/bsims_last.json），
修改後再跑一次，回歸報告（docs/regression_report.md）會列出指標差異和新增／解決的警告。通過驗收標準才接受，否則回滾。

| 欄位 | 說明 |
|---|---|
| 編號 | CS-0001、CS-0002… |
| 項目 | 改了哪個資料（例：`DEF.skills.sig_swordsman` 威力公式） |
| 舊值 → 新值 | |
| 原因 | 哪份報告的哪個數據或警告 |
| 預期影響 | 哪些職業／配點／魔物的勝率、每回合傷害會怎麼變 |
| 測試計畫 | 跑哪些測試（btest 關卡、--sims） |
| 驗收標準 | 例：劍士三種配點對頭目勝率 ≥ 30%，其他職業變化 < 10% |
| 基準 | 修改前的報告日期／版本 |
| 結果 | 通過／回滾，附回歸報告摘要 |
| 核准 | 玩家（規格 §18：數值由玩家核准） |

## CS-0000 v12.0.0 重製基準（2026-10-01）
- 項目：整個戰鬥底層依規格 v1.1 重製（第 1 部草案修訂 2＋第 2 部內容表）。這次**沒有做任何平衡調整**，數值全部照核准的草案。
- 基準：docs/balance_report.md（v12.0.0，30 組 × 5 種魔物 × 6 場）。
- 觀察（只是數據，等玩家決定要不要調）：
  - 初始裝備、Lv24、自動操作下，頭目（古岩魔像 Lv18）只有守護者、龍騎士、異界勇者、機工士贏得了；劍士、魔導士、吟遊詩人、魔劍士、武僧、遊俠對頭目勝率 0%。
  - v11 的同類報告（Lv20、四個技能）也有很多 0%，所以不是這次才變弱，但職業之間差距變大了。
- 結果：作為之後所有修改單的基準。
