# 曙光冒險 技能精簡企劃（草案，2026-11-06）

玩家：「現在的技能數量確實太多了。RPG 的精髓就是用技能打倒敵人，我打算用少量但可升級的技能當作這遊戲的精髓。」
「之前新裝的 pixelfx，乾脆配合這套來做技能的更改。」「先從劍開始。」

## 一、規則

| 項目 | 新規則 | 現在 |
|---|---|---|
| 招數 | **每種武器 8 招** | 每種武器 7〜13 招＋特技，總共超過 150 招 |
| 上場 | **帶 4 招**（技能槽 4 格） | 一樣 4 格，但能放別的來源的招 |
| 留下的 | **只留武器特性**（例：劍＝會心時多削 1 格護盾） | 還有精通、第三被動、特技、共通樹、裝備附帶的招、招牌技 |
| 技能點 | 每升 1 級 1 點；主線頭目第一次打倒 1 點 | 每級 2 點（因為還有共通樹） |
| 等級 | 每招 Lv1〜5：學會花 1 點，之後每級 1 點 | 一樣 Lv1〜5，但每級只是威力 +10% |
| 升級 | 每級威力 +10%，**另外每招都有看得到的變化**（段數、劍氣數、範圍、持續） | 只有數字 |
| 分支 | **Lv3 選 A 或 B**，兩條路打法不同（在城鎮可以改，暫定） | 沒有 |
| 覺醒 | **Lv5 特效變成金色、變大** | 沒有 |
| 解鎖 | Lv1 兩招，Lv5、10、15、20、25 各一招，Lv30 奧義 | Lv1／15／30／35 一次開一排 |
| 特效 | **pixelfx 程式像素特效**：顏色、大小、數量跟著等級和分支變；音效 ZzFX | 原本的特效 |
| 舊存檔 | 技能全部重置、點數全部退回 | — |

### 拿掉的劍招（併進上面）

- 疾風二連、流光連斬 → 疾風連斬
- 一刀天斷、斷鋼一閃 → 破綻突的兩條分支
- 狂刃 → 心眼的「殺意」
- 晨曦之刃 → 破曉千斬的「曉光」
- 特技劍鳴・澄心・碎鋼、精通、鋒芒 → 拿掉

## 三、做法

1. 先做劍：新的 8 招、學招／升級／Lv3 分支的畫面、pixelfx 特效（跟著等級變），放在試玩版。
2. 特效測試加「劍 Lv1／Lv3A／Lv3B／Lv5」可以切換，直接比較升級前後。
3. 劍確定後，其他武器照同一套規則（雙刀、雙劍、雙盾、單手盾要不要獨立：待定）。
