# 廢案：PC 重做（第二版試玩）

狀態：**不採用**（2026-11-05 決定回到直式手機版 v12.154）。

## 內容

以 v12.154 為底，做成電腦專用的橫向版本：

- 畫面：480×270 橫向。
- 野外：8 方向自由移動、放大 1.5 倍、相鄰地圖無縫接起來。
- 戰鬥：每回合各動一次，速度快的先動，畫面上顯示「這回合／下回合」的順序。
- 側面對戰：主角在左邊面向右，主角圖先用暫代圖。
- 操作：鍵盤為主、滑鼠輔助。
- 選單：舊畫面攤成左右兩欄。

第一版試玩裡的時間軸、快／普／重、右側欄、背影戰鬥都已經在第二版拿掉。

## 檔案

| 檔案 | 說明 |
|---|---|
| `web/index.html`、`web/game1.js`〜`game4.js` | 最後發布的可玩版本（試玩連結第 4 版）。圖檔用正式版的 `dist/web/hd`、`dist/web/px`，要在本機跑時把這兩個資料夾複製到 `web/` 旁邊。 |
| `src_pc_recovered.js` | 從發布版拆回來的 PC 專用程式。原本是 `src_pc/` 下的 7 個檔：輸入、文字、舊畫面兩欄、戰鬥、野外、野外道具、選單。建置時註解已被刪掉。 |

原本的 `tools/build_pc.py` 和 `src_pc/` 原始檔沒有推上 GitHub，工作環境重置時遺失了。build_pc.py 的做法是：

1. 把 `src/*.js` 接起來。
2. 用精確字串替換改掉幾十處，例如畫面尺寸、按鍵表、戰鬥座標。
3. 最後接上 `src_pc/*.js` 覆蓋原本的函式。

這次發布版的程式已經包含所有替換結果，可以直接參考。

企劃文件在正式版的 `docs/廢案/`。
